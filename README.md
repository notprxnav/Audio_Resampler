# Multi-Rate Audio Resampler

A Streamlit application that converts WAV audio between sampling rates using
rational polyphase resampling and evaluates distortion.

## Features

- Original and converted audio playback
- Automatic input-rate detection
- Rational resampling
- WAV download
- SNR, MSE, RMSE, correlation, and processing-time measurements
- Waveform and frequency-spectrum comparisons
